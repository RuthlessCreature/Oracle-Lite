## 使用入口

在 Viewer 选择项目，点击“自动配准与训练”，再点击“开始 / 继续运行”。后台逐组处理程序和坐标系；页面显示完成组数、各阶段状态、样本数、未启动原因，并可下载运行记录。服务重启会将未完成作业标为可重新提交，保留已经生成的记录。资料或算法改变时重新求解；二者一致时复用已有配准结果。

命令行也能从配准开始连续执行：

```bash
.venv/bin/python scripts/run_automatic_learning.py \
  --project PROJECT_ID --resume --output OUTPUT_DIRECTORY
```

## 自动标签策略

原生 MSOP 文本中的 Location Definitions 可自动生成点名与 XYZ 提取任务，不依赖人工逐项标注。每条样本保存原文引用、MSOP 哈希和页文本哈希。同页同名点坐标冲突时整页排除。训练和测试按图纸编号隔离，所有修订保持在同一组。数据使用现有 instruction 格式；后续训练不得截断答案，也不能把测试样本混入训练。

该数据集训练的是原文读取能力，不是 CAD 定位、光学选型或方案规划能力。CAD 位置训练需要独立的特征身份与几何一致性核验。模型自评与点到面距离不能自行构成正确标签。将来可以用方向、基准、解析面类型、多假设稳定性等独立约束自动核验，不必把人工审批写成所有标签的硬条件。

# 自动显示候选与实际标记覆盖（2026-10-13）

打开项目的本地模型标记流程现在能从未标记项生成显示候选，而不只核对已有候选。使用同一 CAD/MSOP 源哈希对应的自动配准提案，对每项完整 XYZ 点集作三维检索；常 Z 点组保持在变换后的测量截面上。三角面距离索引保留中心较远的大面，配准起始位置从 CAD 面面积和高度层检索，没有项目固定偏移。

每项必须保留全部点，逐点显示检索距离不超过 0.1 mm，并避开未通过有效性检查的 CAD 面。原文冲突、遗漏坐标系、缺失截面交线或接口上限会保留未标记状态及原因。显示候选先留在内存；本地 Strata 必须接受完整面组、返回相同 FAI 编号和待复核状态，才能写入 `local_model_candidate` 标记。未验证的自动 XYZ 提案将显示置信度限制为 `low`，不能当成已验证配准或训练真值。

任务结束与覆盖完成分别统计。无候选且有未标记项时显示 `blocked`，已处理候选但仍有未标记项时显示 `partial`；只有全部 FAI 均有实际标记时才显示 `completed`。重复打开不重复推理，候选代码、配准提案或源文件改变后才重新核对。

## 本地模型拥有配准选择权

自动配准器只生成刚体变换假设及各假设的完整源点→CAD表面对应、距离和留出误差，不再把算法排序第一的 `best` 自动当成最终配准。每个 Program / Coordinate System 的候选由本机本地模型进行逐点比较；候选顺序使用源哈希固定随机化，避免模型总是偏向列表第一项。模型逐轮选择胜者或弃答；只有模型写入源哈希匹配的 `local_model_registration` 选择记录后，候选生成器才允许使用该变换。单一假设也必须经过模型授权。所有点组仍由几何校验器做完整性、刚体矩阵、逐点距离和CAD落面检查；这些检查只接受或拒绝模型决定，不替模型选变换。非本机推理端点、上下文超限、点组冲突、候选对应不完整或模型弃答时，不生成标记。

这次实现已由配准管线和候选生成单测验证。还没有可用的本地模型服务运行证明，也没有对 613-13599 / 613-16076 实际推理；因此不能宣称任一项目的自动覆盖已提升。真实运行仍需在本机 Strata/Talker 服务就绪后验证模型的逐点判别质量、所有 FAI 覆盖及 Viewer 落面效果。
