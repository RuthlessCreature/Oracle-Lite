# FAI 特征对应与跨项一致性整改

适用于所有通过本地模型定位的项目，不含项目编号、固定面号、固定坐标或单项目例外。版本：feature_integrity.VERSION = 1。

## 验收链

原文测量清单 → 本地模型选择几何候选 → 完整组几何检查 → 本地模型独立逐点核对原页与 CAD 编号叠加图 → 原文特征/实际实例绑定校验 → 跨 FAI 共享特征一致性检查 → 写入有效标记。

XYZ 点组、视觉射线回退、候选面选择三条路径均经过最后的实体复核，不能凭表面命中、点数、间距或模型自评置信度直接通过。源 XYZ 与 CAD 点仍由本地模型选择的对应/变换产生，验证程序不选点、不移动点、不从冲突结果中选择优胜者。

## 源身份

共享身份由源文档ID、打印的程序/坐标范围、原文特征名派生。未打印坐标范围时限定到原始定义页；不能把不同程序/坐标系中的同名特征合并。保留复合坐标系，支持原文连续编号展开。

复核模型必须为每个整数 marker ID 返回 source_names、instance_path 和原文实体对应证据。点名只能来自原文候选清单，不能换名避开冲突。没有打印名称时允许空数组，但仍须逐点确认实例和来源证据；无命名位置暂不能靠名称建立跨FAI身份，这不表示已经完成匿名实体的拓扑融合。

## 冲突

同一源特征对应不同CAD实例时拒绝。唯一命名点/圆标记同时检查显示锚点距离，0.75 mm为显示一致性门限，沿用既有显示定位级别，不是图纸公差、测量准确度或计量验收门限。线/平面可以有多个采样位置，不用点位置相等替代其几何语义。

新候选与既有有效标记冲突时，新候选不写入有效覆盖，既有冲突项也退出有效覆盖；保留坐标和诊断，不默认采用先生成的位置。所有重判仍由本地模型执行。

## 旧记录迁移

旧 auto_marked 记录没有本版 confirmed 特征验证时改为 stale / feature_identity_review_required，坐标不修改，记录保留。提交任务、准备候选和直接匹配三个入口执行幂等迁移，避免“全部已标记”缓存绕过新门槛。新验证元数据随锚点同一次持久化。

## 实际验证与边界

306项相关回归测试通过。历史FAI33/34错误记录回放产生两个共享圆冲突（35.86/38.61mm），回放不写入任何标记。模型复核需重新执行，不能将测试通过解释为所有真实FAI均已正确。独立复核使用相同本地模型的新上下文，并非独立模型或人工计量真值；共识仍可能错误，需要实际正确率评估、更多拓扑/尺寸约束和视觉证据来继续验证。

本次只调整定位与验收框架，未训练新权重，不宣称计量合格或自动规划的准确度已经提升到某个百分比。
