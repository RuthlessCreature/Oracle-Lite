# Oracle 自动改进实施记录

本轮授权：完成不需要人工介入的改进。工程判断由配置的本地模型提出，坐标、几何和设备参数由可复算工具校核。人工复核、实拍、实机标定和计量验收没有被自动改成通过。

## 已实现并验证的功能

1. Viewer 增加“项目工程核查”：对全部原文FAI列出来源页、点位数量、映射数量、偏面距离、候选来源、自评置信度、方法字段缺失和待处理问题，可导出CSV/JSON。
2. 通用三维配准拟合：按坐标系分组，保留点名冲突；重复出现的同一个点不增加独立样本数；检查三维可约束性、反射、逐点残差及留一验证，不自动删异常点。拟合结论仅用于显示几何。
3. MSOP坐标利用：跨页点名引用与本页表格合并，补取对应XYZ的IJK；没有CAD或没有配准时仍保留原文点位。均匀源Z组、共同面和逐点对应分别校验，三维拟合结果不会被XY检索覆盖。
4. 配准结果按源文件哈希绑定。D52仅ALI_ITER获得支持，其余三个坐标系因冲突或残差未通过而保留待处理；不将显示拟合当作工件基准建立。
5. 覆盖状态分开记录：原文FAI、有标记、位置复核、方法方案、现有标记点光学采集、计量验收。完成规划不等于完成测量。
6. 圆柱/环形光源与工件网格碰撞改为三角形穿越检查，能发现三个顶点都在外侧但三角形穿过环壁的情况。
7. 总装增加运动包络筛查，列出候选动作顺序、位移、旋转和潜在干涉。旋转使用保守扫掠球；移动工件方案明确需要工件/夹具变换，不能套用移动相机结果。静态碰撞会阻止可安装结论。
8. 共用背光面板按真实发光面积与外形尺寸查询目录候选；缺少尺寸时保留面积需求，不编造大型光源型号。控制器检查电压范围、电流和功率；不明确的数据不能用来确定配套。
9. 设备资料核查按环光、背光、相机、镜头、控制器及深度传感器分别检查关键字段。校验本地附件SHA256；自动补抓仅访问已有厂家页面所给的具体附件链接，失败原因保留。
10. 增加规划取消入口；服务重启后中断的规划和总装任务变为可重提失败状态，保存已完成步骤。缓存加入坐标/检索/硬件/运动算法版本，旧结果不会被当作当前结果。
11. 三个项目已生成校验归档。下载接口 `/api/viewer/projects/{id}/backup`；恢复接口 `POST /api/viewer/projects/restore` 接收ZIP并验证路径、清单和文件哈希，恢复为新项目，不覆盖原项目。
12. TALKER与Viewer文字推理默认共用本地Strata服务和模型对象；图片显式交给本机辅助视觉模型。原生文本模型无法直接读图时不再把图片发给它假装已读。
13. 大项目决策输入增加无损列式编码：保留全部行、字段及数值精度，并做编解码一致性检查；D52整机合并输入从69,062字符降到55,869字符，没有截断FAI或点位。
14. 训练数据按图纸项目划分，所有修订保持同组；未复核标记进入隔离集，不能作为正确标签训练。预检检查可训练权重和Strata部署链路，未运行权重训练时明确记录 `weights_changed=false`。
15. 第二份X_T的精确schema扩展已完成源实体解码：262,757个节点、6,450个面、18,121条边、11,574个顶点，源拓扑通过。修复B类交线边界和允许空thumb权重的源定义；不以相近schema替代。服务端重新读取原文件也已验证通过，生成6,651个实例面、915,170个三角形；215个严格OCCT无效面仍单独报告，保留为显示预览。

17. 第05步PPT导出绑定当前总装和生成器版本；相机位置和运动表自动分页，完整保留82个曝光位置。浏览器实际点击导出并下载成功，当前共享方案为45页，全部页已逐页检查。图片是Viewer的几何预览，不是实拍照明模拟或高保真供应商装配CAD。
18. 浏览器快速切换项目的迟到响应被隔离；反复切换会释放旧网格资源。Chromium软件渲染回归无页面错误，D52与D868往返切换后的图形资源计数一致。工程检查、主/子渲染和第05步导出均已回归。

## 继续迭代：程序与坐标系作用域

- 点位身份改为点名、测量程序、测量坐标系的组合。不同UP/DOWN中复用点名分别保留；同一作用域内不同XYZ/IJK才记录为冲突。缺少程序且存在多个定义时停止自动映射，不选择第一条原文。
- 只有相邻且标题相同的续页可以继承程序和测量坐标系；更换DATUM/FAI标题后不沿用上页上下文。继承页码保留为来源。
- 配准拟合按程序和坐标系分别分组。某坐标系同时用于多个程序时，旧的不带程序的校准不能通用于两面。
